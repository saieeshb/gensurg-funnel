# The Gen Surgery Funnel

**[surgery.saieesh.dev](https://surgery.saieesh.dev)**

Two cycles of the crowdsourced General Surgery residency application spreadsheets, parsed end to
end and analysed together: **361 applicants with match outcomes** (2024–25) and **1,154 individual
interview invitations across 315 programs** (2025–26).

Every number on the site is generated by a script in [`analysis/`](analysis/) from the two
workbooks in [`data/`](data/). Nothing is hand-entered.

## What it found

- **Interview count is nearly the whole outcome.** 9.1× the odds of a categorical match per five
  extra interviews. Ten or more invitations → 91% categorical; two or fewer → 0%.
- **Signals amplify a strong application; they do not rescue a weak one.** Conversion rises from
  **4.0 of 15** below Step 2 240 to **9.1 of 15** above 270 (r = +0.44, p < 10⁻⁵).
- **Program signalling is worth ~3.9× on the odds of an invitation** (tier-matched OR 3.85,
  95% CI 1.77–8.35), confirmed two independent ways.
- **Past ~60 applications you are buying nothing.** Marginal return falls from +1.9 interviews per
  ten applications to zero.
- **Publications do nothing measurable** for interview count (IRR 1.01, p = 0.85).
- **The season is one day long.** 35% of all invitations landed on Wednesday 22 October 2025.
- **Non-US IMGs face a different market**, not a harder one: 57% of their invitations are
  preliminary, and their invitees score ten points higher than the US MDs who get invited.

Full detail, with the confidence intervals and every reason to distrust each number, is in
[`report.md`](report.md) and on the [methods page](https://surgery.saieesh.dev/methods.html).

## Reproduce it

```bash
git clone https://github.com/saieeshb/gensurg-funnel
cd gensurg-funnel
python3 -m venv venv && ./venv/bin/pip install -r analysis/requirements.txt
cd analysis
../venv/bin/python parse_ii.py       # 2025-26 invitations -> records
../venv/bin/python parse_2425.py     # 2024-25 applicants  -> records
../venv/bin/python analyze.py        # composition, base rates, timing
../venv/bin/python analyze2.py       # tiers, geography, IMG, letters
../venv/bin/python analyze3.py       # clustering, bootstrap, projection
../venv/bin/python combined.py       # both cycles together
../venv/bin/python img_analysis.py   # non-US IMG stratified analysis
../venv/bin/python export_site.py    # -> assets/site.json
```

The scripts read the workbooks from `data/`. Diff a re-run of `site.json` against the committed one
to verify any figure on the site.

To view locally:

```bash
python3 -m http.server 8765
```

## Please read the limits before using any number

These are **voluntary, self-reported** datasets covering roughly **5–6%** of national General
Surgery interview volume. They cannot produce an absolute national rate, only comparisons within
the data. Records are not independent (ICC 0.415 — effective n ≈ 465, not 1,154), and the dataset
cannot detect effects smaller than about ten percentage points, so every null result is a bound
rather than a proof of absence.

The [methods page](https://surgery.saieesh.dev/methods.html) states all of this at the same volume
as the findings, which is the point.
